# The Daily Dome

Derrick Kempf's pitch for the Gumroad Creator-in-Residence program, told as a small-town newspaper. A MADE artes creation.

## Files

- `index.html` is the whole page.
- `assets/images/` holds the drawings (dewd2 to dewd16).
- `assets/fonts/FrankieNewsRegular.woff` is the headline font.

## Publish with GitHub Pages

1. Create a new public repository on GitHub, for example `daily-dome`.
2. Upload everything in this folder (keep the `assets` folder structure).
3. Go to **Settings > Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. In a minute or two the site will be live at `https://<your-username>.github.io/daily-dome/`.

To use your own domain, add it under **Settings > Pages > Custom domain**.

## Editing

All copy lives in `index.html`. To swap a drawing, replace the file in `assets/images/` with one of the same name.
